13⚠️ 문제가 생겼을 때

① 코드만 나오거나 Canvas 미리보기가 안 될 때

현재 포트폴리오의 내용은 그대로 유지하고, HTML, CSS, JavaScript를 하나의 단일 HTML 파일로 다시 정리해줘. 외부 라이브러리, CDN, React, 백엔드 기능은 사용하지 말고 브라우저 기본 기능만 사용해줘. 코드가 너무 길어지지 않도록 복잡한 효과와 불필요한 기능은 줄여줘. 가능하면 Gemini Canvas에서 바로 미리볼 수 있게 만들어줘.

② 그래도 Canvas 미리보기가 안 될 때

미리보기가 나오지 않아도 괜찮습니다. 완성된 HTML 파일을 다운로드한 뒤 브라우저에서 직접 열어서 확인합니다.
  1. Gemini에서 HTML 파일 다운로드
  2. 브라우저에서 열기
  3. 내용과 디자인 확인
  4. 수정이 필요하면 Gemini에서 수정
  5. 다시 다운로드해서 확인
Canvas 미리보기는 편리한 확인 방법일 뿐입니다.
미리보기가 안 나와도 HTML 파일이 정상 실행되면 작품은 완성된 것입니다.
